# 班级工作台（原型）

老师本机的班级管理工具：名单 / 小组 / 成绩（折线图）/ 文字记录 / 班级日志，一键生成纯静态学生端站点并推送 git（配合 EdgeOne Pages 自动部署）。数据以 CSV 形式 100% 本地存储，零第三方依赖（Deno 内置 API + 自写 CSV/Markdown/SVG 图表）。

设计方案见：`../班级工作台设计方案.md`

## 快速开始

```bash
# 需要：Deno ≥ 2.9、git
deno task seed     # 生成示例数据（40 名学生 / 8 组 / 5 次考试 / 4 篇日志 / 40 条积分记录）
deno task dev      # 启动，浏览器打开 http://127.0.0.1:7788/
```

体验路径：总览 → 各页面随便看 → **发布中心** → 「生成站点并发布」→ 「打开学生站预览」（`/preview/`）→ 成绩查询输入姓名试试。

## 目录结构

```
├─ main.ts            # 服务入口：API 路由 + 静态服务 + /preview 预览
├─ src/
│  ├─ csv.ts          # RFC4180 CSV（UTF-8 BOM，Excel 双击直开）
│  ├─ store.ts        # 数据层：data/ 下所有 CSV 的读写
│  ├─ journal.ts      # 班级日志（一天一篇 md + front-matter publish 开关）
│  ├─ markdown.ts     # 极简 Markdown 渲染（先转义，无 XSS）
│  ├─ gitcmd.ts       # git 封装：自动 init、-c 注入身份、无远程优雅降级
│  ├─ ssg.ts          # 学生端静态站生成器 → site/
│  └─ seed.ts         # 确定性示例数据
├─ web/               # 工作台前端（Vue3 vendored，无构建步骤）
│  ├─ app.js          # 全部视图（总览/名单/小组/成绩/记录/日志/发布）
│  └─ vendor/         # vue.global.prod.js、chart.js（自写 SVG 图表）
├─ data/              # 私有数据仓库（独立 git，首次备份时自动 init）
└─ site/              # 公开站点产物（独立 git，仅放生成结果）
```

## 发布与备份

- **发布** = 本地渲染静态站 → `site/` 内 git commit →（有远程则）push。日志中 `publish: false` 的篇目永远不会出现在公开站。
- **备份** = `data/` 内 git commit →（有远程则）push。
- 配置远程（一次性）：

```bash
cd data && git remote add origin <私有仓库地址>   # 备份用
cd site && git remote add origin <公开仓库地址>   # 发布用，需在 EdgeOne Pages 控制台连接
```

EdgeOne Pages 侧配置：构建命令留空、输出目录 `/`（站点由工作台在本地渲染完成，push 即部署）。

## 原型范围（对应设计方案）

已实现：名单（**Excel/CSV 文件或粘贴导入**：自动识别学号·姓名·性别·小组·备注列、多 Sheet 自动挑选、CSV 兼容 GBK、文件里的新组自动创建；防抖自动保存、覆盖导入时保留未提供的小组归属；**启动时控制台输出设置导向**）、小组、座位表（多场景、单击交换/双击移出/点选放人、随机排座、按名单顺序排、任意位置插删排列、行列尺寸一键调整、**一键操作撤销**、导出 PNG）、成绩（九科模型：Excel 文件上传 / 粘贴导入，**自动挑选含表头的 Sheet、GBK 编码兜底**，表头自动识别学号·姓名·科目列，忽略干扰列与汇总行；主科 150 分制按科目设置满分，**科目改名自动迁移历史成绩列**，分数自动钳制到 [0, 满分]；**总分平均/分数段分布只统计全科实考学生**，缺考者在总分列显式标注；导出 Excel/CSV；个人趋势折线图按科目切换）、**个人积分**（加分/扣分流水：日期·分值·原因，Tab/逗号粘贴即记；按月汇总排行可选**按学生或按小组**，可选月份或全年，按学生/月份/类型筛选历史；「表扬/谈话」文字记录可一键转积分；发布可选生成**积分光荣榜**公开页）、文字记录（按学生/类别筛选）、日志（Markdown + 预览 + 公开开关 + **粘贴/上传配图**）、发布中心（范围勾选并记忆 / **发布前自动备份数据** / **取消勾选后清理旧产物** / 预览 / 备份）、示例数据（**覆盖前自动 git 留档**）、**暗色模式**、**服务仅监听本机回环地址**、全局未保存修改守卫、**隐藏的数据清空入口**（双击左下角页脚文字显示按钮，三次确认，清空前自动 git 留档）。

暂未实现（M2 收尾）：学生个人档案时间线、`deno desktop` 打包、自动更新。

已知取舍：

- 科目与各科满分在 `data/config.json`（默认高一九科，**主科语数英 150 分、其余 100**，总分 1050），成绩页「⚙ 科目设置」面板可直接调整；改名会自动迁移历史成绩文件的列，删除科目后该列将在下次保存成绩时移除；
- 成绩明细文件为 `scores/<exam_id>.csv`，每科一列，总分为派生值不落盘；满分按科目设置（主科 150），暂不支持按考试单独设满分；
- 导入按**学号优先**匹配名单（学校导出表以学号为准，姓名仅兜底）；
- 公开站成绩查询需**姓名 + 学号后四位**：学生数据按 `sha256(姓名|学号后四位)` 拆成独立文件，站点上不可枚举、不可反查；班级平均分为公开数据（不含任何个人信息）；
- 后端整表替换式保存（数据量极小，简单可靠），并发编辑不适用；
- 服务绑定 `127.0.0.1`，仅本机可访问；如需局域网协作请自行加反代与鉴权。
